# Concurrent File System Simulator 📂

### 🚀 Overview
Este proyecto es un simulador avanzado de un sistema de archivos concurrente desarrollado para la clase de Sistemas Operativos. Implementa la gestión de permisos, asignación de bloques y manejo de concurrencia para garantizar la integridad de los datos.

### 🛠️ Key Features
- **Gestión de Permisos:** Simulación de lectura/escritura basada en niveles de usuario (Fundamentos de Ciberseguridad).
- **Concurrencia:** Manejo de condiciones de carrera mediante semáforos/monitores.
- **Asignación de Bloques:** Implementación de estructuras para la organización lógica del almacenamiento.

### 🛡️ Security Perspective
Se aplicó el principio de **Privilegio Mínimo** en la gestión de permisos para asegurar que los procesos solo accedan a los bloques autorizados, mitigando riesgos de corrupción de datos.
